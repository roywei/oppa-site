# Fun materials

- `oppa-gangnam-style-poster.png`, `oppa-family-style-poster.png`: 1080×1350 posters from `src/poster-gangnam.html` and `src/poster.html`, rendered with headless Chrome. The face with sunglasses, `../assets/oppa-face-shades.png`, was drawn by Codex's image tool from the OPPA face (`gen/BRIEF-shades.md`).
- `oppa-family-style-vertical.mp4`: 14.5 s vertical clip for TikTok, Reels and Shorts with the Family Style poster bouncing on the beat. The beat is original, from `src/beat.py`; the background is `src/bg.html`; the ffmpeg graph is `src/clip.filter`.
- `x-posts.md`: launch posts for X.
- `gen/`: Codex inputs and outputs: the sunglasses face (`oppa-face-shades.png`, from the fixed face; `-v1` was drawn from the face before the temple fix) and the first full-scene attempts, kept for reference and not used.

The Rivera family is made up. The Gangnam Style nod is a parody: no song, lyrics or real person's likeness.
